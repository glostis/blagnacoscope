# Blagnacoscope

I ran a scraper that gathered all [ADS-B](https://en.wikipedia.org/wiki/Automatic_Dependent_Surveillance%E2%80%93Broadcast)
pings emitted by aircraft around the [Toulouse Blagnac — LFBO](https://en.wikipedia.org/wiki/Toulouse%E2%80%93Blagnac_Airport)
airport in a ~4 month timeframe between October 2023 and February 2024.

The goal of the project was to be able to answer the following questions:

- How many aircraft takeoff from and land at LFBO each day?
- Where do these aircraft come from, where are they going to?
- Which runway is used when?

The Streamlit instance at [blagnacoscope.glost.is](https://blagnacoscope.glost.is) contains dashboards that enable you
to explore the data.
